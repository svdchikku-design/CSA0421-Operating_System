=== Assumptions: node = 1 server with 10 Gbit/s network (1,250 MB/s) and disks delivering 800 MB/s; 100 TB of useful data; node availability 99.5 % ===
NFS (1 server): read capacity 800 MB/s, write capacity 800 MB/s (all clients share it)
DFS (6 nodes, 3 replicas): read capacity ~ 4800 MB/s (every replica can serve a read: x6); write capacity ~ 1600 MB/s (each byte is written 3 times: x6/3)

=== Availability ===
NFS, one server: availability 99.500% -> down 43.8 hours per year (0.5 % of the time); all users affected
2 independent replicas: data unavailable only if all 2 fail together: unavailability 2.50e-05 -> 788.4 seconds per year (in practice: correlated failures such as one rack or power feed make it larger)
3 independent replicas: data unavailable only if all 3 fail together: unavailability 1.25e-07 -> 3.9 seconds per year (in practice: correlated failures such as one rack or power feed make it larger)

=== Storage used for 100 TB of data ===
NFS, 1 copy: 100 TB (+ RAID overhead e.g. RAID 6 on 8 disks: 133 TB raw);   DFS with 3 replicas: 300 TB raw (3x);   erasure coding 6+3: 150 TB (1.5x) with the same two-failure tolerance
